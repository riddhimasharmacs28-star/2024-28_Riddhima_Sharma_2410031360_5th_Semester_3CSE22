## Internship Project

### Sentiment Analysis on Movie Reviews

The primary project completed during the internship was Sentiment Analysis on Movie Reviews.

The project focused on analyzing movie-review text and determining the sentiment expressed in the reviews. This provided practical exposure to working with textual data and understanding how analytical and AI-based techniques can be applied to extract meaningful information from unstructured text.

The project contributed to my understanding of:

- Text-based data analysis.
- Sentiment classification.
- Data preprocessing concepts.
- Extracting insights from review data.
- Applying analytical thinking to real-world datasets.
